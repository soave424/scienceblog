# **App Name**: Scholarly Science Log

## Core Features:

- Blog Editor & Multimedia Management: Users can compose scientific observation reports within a rich editor, upload photos/sketches to cloud storage, and seamlessly embed them with unique URLs in their posts.
- AI-Powered Image Observation Tool: Upon image upload, an AI Vision API tool analyzes visual content to identify key objective observation points and generates specific, targeted questions for the user.
- Real-time AI Writing Coach: An AI chatbot tool continuously analyzes the user's text for context and objectivity, providing real-time, Socratic-style questions and feedback via a sidebar to promote precise scientific writing.
- Automatic Draft Saving: The system automatically saves writing progress to a temporary table in the central database in real-time, preventing data loss during creation.
- Virtual Observation Multimedia: Users can access high-quality video and photo resources of the butterfly life cycle, capture specific frames from videos, and automatically embed them into their blog posts.
- Fact vs. Opinion AI Analyzer: An AI tool analyzes user text describing scientific images, flagging subjective statements and providing guidance for rewriting them with objective, fact-based descriptions based on database rules and LLM integration.
- Central Data & Image Storage: A robust system manages user profiles, blog posts, observation progress, AI chat logs in a central database, and stores all multimedia files in a scalable cloud image storage with secured access (e.g., Presigned URLs).

## Style Guidelines:

- Primary color: A sophisticated, calming blue (#3962AC) to evoke intelligence and a clear, focused academic environment, providing strong contrast on a light background.
- Background color: A very light, subtle blue-grey (#EDF1F7) as the main backdrop, maintaining visual harmony with the primary color while ensuring readability.
- Accent color: A vibrant yet analogous cyan (#4DC2D5) to highlight interactive elements and provide a fresh, inviting visual cue, contrasting well with the primary and background hues.
- Headline font: 'Space Grotesk' (sans-serif) for its modern, scientific, and clear presence, suitable for titles and important labels.
- Body font: 'Inter' (sans-serif) for its high legibility and objective feel, ensuring comfortable reading for longer scientific texts and observations.
- Use clean, vector-based icons that visually communicate scientific themes and user actions clearly, avoiding overly decorative elements to maintain a professional and academic aesthetic.
- A structured, two-column layout with the primary content editor centrally placed and a dynamic sidebar for AI feedback and multimedia controls. Prioritize clear hierarchy and ample whitespace to enhance focus on content.
- Subtle, quick feedback animations for interactive elements, such as AI response streaming, button clicks, and content transitions, to provide a responsive and engaging user experience without distraction.
